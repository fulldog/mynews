# 抖音推广口播脚本（摸鱼资讯）

> 使用说明：3 个脚本对应 3 种内容形态，建议间隔发布。
> ⚠️ 转化路径现实约束：抖音挂不了微信小程序链接，转化全靠**口播名称 + 评论区置顶 + 主页简介**。视频画面中**不要出现小程序二维码**（平台判定站外导流会限流）。

---

## 脚本 1｜痛点对比款（15-25 秒，主推）

**分镜脚本**：

| 时间 | 画面 | 口播/字幕 |
|---|---|---|
| 0-3s | 手机桌面，七八个App图标特写 | （字幕）看个热搜要装8个App？ |
| 3-6s | 手指快速切换微博/知乎/B站，动作夸张 | 找个热点来回横跳，一天电量掉一半 |
| 6-10s | 录屏：打开摸鱼资讯首页，快速滑动13个板块 | 我现在只用一个页面——微信里搜「摸鱼资讯」 |
| 10-16s | 录屏特写：榜单逐条滚动，标题+热度 | 全网热榜聚合在一起，每条30秒扫完，没有算法推荐，看到的就是真实TOP榜 |
| 16-22s | 回到人脸/桌面，指着屏幕 | 上班摸鱼、下班充电都够用。微信搜一搜：摸鱼资讯，这四个字 |

**发布文案**：热搜党集合📱一个入口替代8个App #效率工具 #摸鱼神器 #热搜 #手机技巧

---

## 脚本 2｜沉浸式录屏款（30-40 秒，信任型）

**结构**：全程录屏 + 旁白，不露脸，适合批量做

| 段落 | 内容 |
|---|---|
| 开场 0-5s | 录屏首页从上往下滑，旁白：「这是我每天早上刷的一个页面，全网热榜都在这」 |
| 5-15s | 依次点开热门社区/IT科技/程序员区，旁白：「社区热帖、科技动态、技术圈大事，13个类目按板块排好，锚点直接跳」 |
| 15-25s | 演示点击条目→复制链接，旁白：「想看原文的，一键复制链接去浏览器，它只给你标题和热度，正文不搬运，很克制」 |
| 25-35s | 演示下拉刷新、页面底部「数据更新于 xx:xx」，旁白：「数据定时更新，页面加载也快。名字叫摸鱼资讯，微信搜一搜就有了，不用注册，打开就能用」 |

**发布文案**：信息差就是这样被拉开的 #资讯 #互联网 #效率 #打工人

## 脚本 3｜剧情反差款（20-30 秒，易起量）

**结构**：办公室情景

| 时间 | 内容 |
|---|---|
| 0-4s | 同事A慌张：老板刚在群里提了个热点，谁知道怎么回事？ |
| 4-8s | 同事B淡定掏出手机：等等，我看看。打开摸鱼资讯，3秒定位相关热帖 |
| 8-14s | 特写：榜单上该话题排在前列，点开复制链接 |
| 14-20s | 同事A震惊：你怎么这么快？B：全网热榜都在这一个页面里，微信搜「摸鱼资讯」，你也能这么快 |
| 20-25s | 结尾字幕：摸鱼要快，姿势要对｜微信搜一搜：摸鱼资讯 |

**发布文案**：老板点名热点时，反应速度就是职场能力😎 #职场 #摸鱼 #搞笑 #办公室日常

## 抖音专属运营建议

| 项 | 建议 |
|---|---|
| 主页简介 | 写「微信搜一搜：摸鱼资讯｜全网热榜聚合工具」（抖音简介不拦截微信二字，但正文与评论区敏感度更高） |
| 评论区置顶 | 「微信搜一搜：摸鱼资讯，打开就能用」——自己小号先问「在哪下载」，主号回复 |
| 画面红线 | ❌ 二维码 ❌ 微信图标 ❌ 「扫码」手势；✅ 口播名称 + 搜索框录屏（录屏里输入「摸鱼资讯」四个字是可以的） |
| 投放 | 脚本1数据好就投 DOU+（100-300 测试），定向：18-35岁/一二线/兴趣标签：科技、职场、互联网 |
| 频率 | 每周 2-3 条，同一模板跑通后换板块做系列（程序员版/学生版/职场版） |
