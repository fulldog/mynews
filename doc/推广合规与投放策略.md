# 推广总纲：合规红线与投放策略

> 适用：doc 目录下三份平台文案。先读本文，再发内容。
> 更新：2026-11-13

## 一、核心转化路径（三个平台通用）

抖音/快手/小红书都**挂不了微信小程序**，转化链路只有一条：

```
视频/笔记 植入名称「摸鱼资讯」
      ↓
用户打开微信 → 搜一搜 → 输入「摸鱼资讯」
      ↓
小程序名片（头像+简介，见 REVIEW.md）→ 打开即用
```

**名称是唯一的转化入口**，所以：
1. 名称必须好打字、无生僻字（「摸鱼资讯」四个常用字，OK）
2. 头像和简介要提前在后台配好（用户搜到后的 3 秒决定去留）
3. 同名小程序若存在混淆，考虑注册商标后用「名称+商标」保护

## 二、平台红线对照表

| 平台 | 高危动作 | 后果 | 替代做法 |
|---|---|---|---|
| 小红书 | 正文/图片出现「微信」、小程序码、二维码 | 限流、禁评、封号 | 全文只说「搜一搜」，搜索框截图代替二维码 |
| 小红书 | 笔记挂商品链接但内容不符 | 违规 | 纯内容笔记，不挂链 |
| 抖音 | 画面出现二维码/微信图标/「扫码」手势 | 判定站外导流限流 | 口播名称 + 搜索框录屏 |
| 抖音 | 评论区大量发联系方式 | 判定营销号 | 只置顶一条，小号互动自然化 |
| 快手 | 视频中口播「加我微信xxx」 | 限流 | 只说小程序名称，不说私人号 |
| 全平台 | 「最全/第一/全网最快」极限词 | 广告法风险，平台删帖 | 用「一站式」「聚合」「高效」 |
| 全平台 | 虚构数据（如「500万人在用」） | 虚假宣传 | 用真实数字：13个类目、330条榜单 |
| 全平台 | 搬运第三方平台Logo做封面 | 侵权 | 自制界面截图+大字标题 |

## 三、内容合规注意（与小程序本身相关的表述边界）

1. **不承诺更新频率**：文案里说「定时更新」「天天更新」可以，别写死「每5分钟」（上游接口非官方，中断时与文案矛盾）。
2. **不说「官方」**：避免「最全官方热榜」表述——你是聚合方，不是官方。
3. **版权口径一致**：对外文案强调「只给标题和热度，原文去来源平台看」——这既是事实，也是最好的版权免责叙事。
4. **不提具体数据接口来源**（momoyu）：对外统一说「公开热榜数据」。

## 四、投放节奏建议（8 周冷启动）

| 周 | 动作 | 目标 |
|---|---|---|
| 1 | 三个平台各发 2-3 条基础内容（本文案），不加投 | 测内容基础数据 |
| 2 | 数据复盘：哪个平台完播/互动最好，集中火力 | 确定主战场 |
| 3-4 | 主战场加倍产出（日更模板款+周更长文案款），小额投流 | 涨粉与搜索词铺量 |
| 5-6 | 结合「今日热点速览」日更模板做系列，蹭当日热点流量 | 稳定自然流量 |
| 7-8 | 评估转化：用小程序侧数据（分享次数、打开来源）判断各平台效果 | 决定长期投入比例 |

## 五、效果衡量（没有埋点也能看）

| 指标 | 看哪里 |
|---|---|
| 各平台引流效果 | 小程序后台「统计-来源分析」的场景值/分享趋势，投放后看整体打开量拐点 |
| 搜索词转化 | 用户搜「摸鱼资讯」进入的比例（搜一搜来源） |
| 内容质量 | 平台侧完播率/点赞藏比，>10% 互动率的内容值得加投 |

## 六、一句话总结

**名称即入口、口播即转化、红线即生死。** 所有内容围绕「让用户记住并打出『摸鱼资讯』四个字」，所有图片不出现任何二维码。
